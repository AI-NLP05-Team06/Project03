# KDIC RAG 학습용 검색기 — 1단계

이 프로젝트는 제출된 `chunks.jsonl`이 실제 질문 검색에 어떻게 사용되는지 눈으로 확인하기 위한 작은 프로그램입니다. 외부 API, 임베딩 모델, 별도 라이브러리가 필요하지 않습니다.

## 지금 구현된 흐름

```text
사용자 질문
→ 업무 필터 선택
→ 해당 업무의 청크만 후보로 제한
→ 단어와 한글 2글자 조각을 이용한 BM25 검색
→ Top-K 결과와 점수 표시
→ 원문 내용과 공식 URL 확인
```

아직 LLM 답변 생성은 넣지 않았습니다. 검색 결과를 먼저 이해하고 검증한 다음 임베딩 검색과 답변 생성을 추가하기 위한 의도입니다.

## 실행 방법

1. `실행하기.bat`을 더블클릭합니다.
2. 브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:8501`을 엽니다.
3. 질문을 입력하고 업무 필터와 Top-K를 선택합니다.
4. 종료할 때는 열린 명령창에서 `Ctrl+C`를 누릅니다.

Python 3.10 이상을 권장합니다. 외부 패키지 설치는 필요하지 않습니다.

## 팀원에게 공유하는 방법

`KDIC_RAG_학습용검색기_팀공유.html` 파일 하나만 전달하면 됩니다. 팀원은 파일을 내려받아 더블클릭하면 되며 Python이나 서버가 필요하지 않습니다.

- 메신저에서 HTML 첨부를 차단하면 ZIP으로 압축해 전달합니다.
- 검색 데이터와 검색 기능이 HTML 안에 포함되어 있어 검색 자체는 오프라인에서도 동작합니다.
- `공식 원문 페이지 열기`는 인터넷 연결이 필요합니다.
- 이 파일에는 공개 웹페이지에서 수집한 청크 내용이 포함되어 있으므로 프로젝트 팀 내부 공유용으로 사용합니다.

## 화면에서 꼭 비교할 것

1. 같은 질문을 `전체 업무`로 검색합니다.
2. 정확한 업무를 선택해 다시 검색합니다.
3. 다른 업무의 비슷한 내용이 사라지는지 확인합니다.
4. Top-K를 3, 5, 10으로 바꾸며 정답 근거가 몇 위인지 확인합니다.
5. 청크 ID, 상위 문서 ID, 원문 URL의 관계를 확인합니다.

## 파일 역할

- `data/chunks.jsonl`: 검색 대상인 427개 청크
- `rag_core.py`: 데이터 로딩, 업무 필터, BM25 검색
- `app.py`: 검색 결과를 보여주는 웹 화면
- `test_search.py`: 데이터와 검색 동작의 기본 검사
- `실행하기.bat`: Windows 실행 파일

## 테스트 방법

프로젝트 폴더에서 다음을 실행합니다.

```powershell
python -m unittest -v test_search.py
```
