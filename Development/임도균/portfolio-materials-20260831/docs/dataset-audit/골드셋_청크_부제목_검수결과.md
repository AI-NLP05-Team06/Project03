## 먼저 수정해야 할 데이터 구조

### 1. 중복 칼럼명

첫 번째 `도메인(원본)` 칼럼의 실제 값은 `업무질문`이므로 칼럼명을 `카테고리`로 변경해야 한다.

현재:

```text
질문ID | 도메인(원본) | 도메인(원본)
Q001   | 업무질문     | 예금자보호제도
```

권장:

```text
질문ID | 카테고리 | 도메인(원본)
```

### 2. 질문 ID 중복

엑셀 행 30~39의 질문 ID가 모두 `추가질문`이다. `question_id`는 고유해야 하므로 `Q029`~`Q038`처럼 서로 다른 ID를 부여해야 한다.

### 3. 중첩 배열 오류

엑셀 34행의 `gold_chunk_ids`가 이중 배열이다.

```json
[["BI-001_chunk_001", "BI-001_chunk_003"]]
```

질문이 미성년자 예금에 관한 것이므로 다음처럼 정리하는 것이 가장 정확하다.

```json
["BI-001_chunk_003"]
```

`gold_primary_chunk_ids`도 `["BI-001_chunk_003"]`으로 맞추는 것을 권장한다.

## 새 판단 칼럼 간 충돌

다음 행은 아래 값이 동시에 설정되어 있다.

```text
gold_answerable = TRUE
gold_requires_clarification = TRUE
gold_expected_action = ask_clarification
```

현재 질문만으로 답할 수 없어 추가 질문해야 한다는 설계라면 `gold_answerable`은 `FALSE`가 자연스럽다.

- 행 30
- 행 31
- 행 32
- 행 33
- 행 35
- 행 38
- 행 39

특히 행 39는 `gold_answerable_status=answerable`이면서 `gold_expected_action=ask_clarification`이라 두 필드 중 하나를 반드시 변경해야 한다.

## 권장 원칙

- `gold_expected_action=ask_clarification`인 질문을 **추가 질문 정책 평가용**으로 사용할 경우:
  - `gold_answerable=FALSE`
  - `gold_requires_clarification=TRUE`
  - `gold_document_ids=[]`
  - `gold_section_titles=[]`
  - `gold_chunk_ids=[]`
- 모호한 질문에서도 **검색 후보 적중 여부를 함께 평가**하려면:
  - 청크를 유지할 수 있지만, 모든 청크의 부제목을 기록
  - primary/supporting 구분
  - `multi_chunk_required`와 `gold_evidence_requirement`를 청크 구성에 맞게 설정
