KDIC 검색 품질 비교 대시보드 V3

1. 실행
- KDIC_검색평가_비교대시보드_V3.html을 더블클릭합니다.
- XLSX·ZIP 분석 기능은 화면의 외부 라이브러리를 불러오므로 인터넷 연결이 필요할 수 있습니다.

2. 검색 결과 추가
- 평가 결과 ZIP, CSV, JSON, JSONL, XLSX를 화면에 끌어 놓습니다.
- 자동 인식이 실패하면 ‘칼럼 호환성 설정’을 누릅니다.
- 파일·시트를 고른 뒤 평가 ID, 질문, 업무, Gold 청크, 검색 청크와 지표 칼럼을 직접 연결합니다.
- 8개 지표 중 하나 이상은 반드시 연결해야 합니다.

3. 비교 결과 관리
- 색상 사각형을 눌러 검색 방식별 차트 색상을 바꿀 수 있습니다.
- ‘보관’을 누르면 데이터는 남아 있지만 차트·표·CSV·AI 분석 ZIP 비교에서는 제외됩니다.
- 보관함의 ‘다시 비교’를 누르면 즉시 복원됩니다.
- ‘삭제’와 ‘완전 삭제’는 데이터를 지우므로 다시 사용하려면 결과 파일을 업로드해야 합니다.

4. 베이스라인 다이어그램
- 검색 방식을 선택한 뒤 Dense, Structured, Hybrid, Reranker, Parent-Child 프리셋을 적용할 수 있습니다.
- ‘단계 포함/제외’ 버튼을 누르면 파이프라인에서 해당 단계가 추가되거나 빠집니다.
- 아래 다이어그램의 단계 카드를 누르면 선택 상태와 설명이 표시됩니다.
- 직접 추가할 단계 이름을 입력하면 실험 전용 단계를 만들 수 있습니다.
- 검색 방식별 다이어그램 설정은 브라우저에 저장됩니다.

5. 화면 설정과 내보내기
- 우측 상단에서 다크모드와 라이트모드를 전환합니다.
- 비교표 CSV와 AI 분석용 ZIP에는 현재 비교 중인 검색 방식만 포함됩니다.
- 보관된 방식은 복원한 후 내보내면 다시 포함됩니다.

주의
- 결과와 설정은 각 사용자의 브라우저 저장 공간에 보관됩니다.
- 다른 PC와 자동 동기화되는 실시간 협업형 서비스는 아닙니다.
