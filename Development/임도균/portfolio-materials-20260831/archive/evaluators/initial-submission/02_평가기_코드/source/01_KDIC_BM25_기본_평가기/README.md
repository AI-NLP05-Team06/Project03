# KDIC BM25 기본 검색 평가기

형태소 분석기를 사용하지 않는 기본 BM25 기준선입니다. `chunks.jsonl`의
`content`를 Unicode NFKC 정규화한 뒤 한글·영문·숫자 덩어리를 정규식으로
추출하여 검색합니다.

## 고정 조건

- 검색 방식: BM25
- 토큰화: 기본 정규식 토큰화(형태소 분석 없음)
- BM25 파라미터: `k1=1.5`, `b=0.75`
- Top-K: 10
- 업무 필터: Gold 업무 사전 필터
- 평가 데이터와 지표: Dense·BGE-M3 Sparse 평가와 동일

외부 API, API 키, GPU는 필요하지 않습니다. 다음 실험인 BM25-Nori와의 차이는
한국어 형태소 분석 여부입니다.
