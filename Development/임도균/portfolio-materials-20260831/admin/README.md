# 챗봇 운영 관리자

## 기준 코드

`aws-snapshot-2026-08-31/`은 당시 AWS 파일시스템에서 읽기 전용으로 가져온 운영 소스입니다. GitHub main과 서버의 미커밋 수정이 달랐기 때문에, 운영 디렉터리를 덮어쓰지 않고 별도로 보관했습니다.

- UI: `kdic_deploy_assets/kdic-admin-ui.html`
- 관리자 API: `kdic_deploy_assets/kdic_admin_extension_aws.py`
- 설정·프롬프트·평가·데이터 관리: 같은 폴더의 관련 Python 모듈
- 캐시 저장 계층: `kdic_deploy_assets/kdic_postgres_store.py`
- 연동 의존성: 팀원 챗봇 core·router·pipeline·answer 모듈
- 서버 서비스·프록시 예시: `deploy/`

원본 경로 구조를 유지했습니다. 환경변수와 실제 DB/데이터는 포함하지 않습니다. 테스트 없이 이 폴더를 운영 서버에 통째로 복사하지 마세요.

## 기능 묶음

- 운영 모니터링: 기간별 통계, 챗봇 로그, 질의 캐시 관리
- 챗봇 고도화: 파이프라인, 이름 있는 파라미터 설정, 검색 평가, 답변 비교, 프롬프트 설정
- 청크 관리: 수집·재수집·미리보기와 저장 청크 조회·변경
- 보안·연동: 가드레일과 API 키 관리
- 반영센터: 변경 초안 확인·승인·이력·복구

기능의 세부 지원 범위는 소스와 실제 런타임 구성에 따릅니다. 이번 아카이브 업로드는 기능 전체 E2E 재시험이 아닙니다.

## 변경 출처

`history/query-cache-admin-c1456f4.patch`는 로컬 `admin-query-cache`에서 관리형 질의 캐시와 반영센터 연동을 추가한 두 커밋의 차이입니다. GitHub main과 일부 변경이 중복될 수 있으므로 그대로 적용하는 배포 스크립트가 아닙니다.

로컬 `admin` 브랜치에 남은 다른 미커밋 수정도 업로드 과정에서 변경하거나 폐기하지 않았습니다. 최신 파일 선정 근거와 원본 해시는 전체 inventory에 기록합니다.
