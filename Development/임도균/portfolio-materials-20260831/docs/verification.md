# 자료 업로드 검증 기록

## 확인한 범위

| 검사 | 결과 |
|---|---|
| Python 소스 구문 분석 | 168개 통과 |
| 독립 JS/MJS 구문 검사 | 14개 통과 |
| 노트북 출력·실행 횟수 제거 | 30개 확인 |
| 검색지표 단위 테스트 | 7개 모듈 × 4건 = 28건 통과 |

| 비밀정보 패턴 검사 | 게시 대상에서 탐지 0건 (설명용 user:pass 예시는 제외) |
| 발표자료 내 이미지 | 중복 제외 23개 확인 |

PEM 개인키, 일반적인 공급자 API 키, AWS 액세스키 ID, JWT, 자격증명이 들어간 연결 URL, 주요 환경변수의 하드코딩 값을 검사했습니다. ZIP 안의 소스 및 Office 문서 XML도 검사했습니다. 자동 검사만으로 모든 비밀정보 부재를 보증하지는 않습니다.

## 검증하지 않은 범위

- 최신 Colab에서 모든 과거 평가 패키지 재실행
- 실제 LLM·임베딩 API를 사용하는 유료 실행
- 모든 프런트엔드 프로젝트의 재빌드 또는 모든 브라우저 상호작용
- 운영 DB 마이그레이션, 청크 적재, 설정 반영·롤백
- 과거 평가 지표의 통계적 타당성 또는 금융 안내의 현재 유효성

이번 검증은 **자료의 보존·공유 준비 검사**입니다. 전체 시스템 E2E 시험이나 운영 배포 완료를 의미하지 않습니다.

`docs/inventory/files.json`에는 가져온 산출물의 출처와 전후 해시가 있습니다. 이번에 추가한 README 등 설명 문서는 해당 원본 산출물 목록과 구분되며 Git 커밋으로 관리합니다.
