# 과거 검색평가 실행 기록

각 하위 폴더는 당시 대시보드에서 내보낸 검색 평가 결과와 분석 코드입니다. 운영 사용자의 실제 대화 로그가 아니라 평가 질문 기반의 실험 자료입니다.

- 데이터셋·필터·청크 버전과 K가 서로 다를 수 있습니다.
- 평균 비교 CSV 및 AI 분석 문구는 과거 산출물로 보존합니다.
- 여러 지표의 단순평균·개선/악화 분류를 검증된 공식 종합점수로 해석하지 않습니다.
- 수치를 새로 계산하거나 당시 평가표의 Gold를 변경하지 않았습니다.
- LLM의 분석 문구는 계산된 지표와 질문별 근거를 대체하지 않습니다.
