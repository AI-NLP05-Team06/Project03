# 공유 정책

## 포함

독립 실행 도구, 평가기 소스와 코드 전용 ZIP, 출력이 제거된 노트북, 검수된 평가표·칼럼 설명, 과거 검색 실험 결과, 대표 발표본, AWS 운영 코드의 읽기 전용 스냅샷, 팀 작업임을 명시한 역할 설명.

## 제외

- 실제 API 키, 관리자 인증 토큰, SSH 개인키, 환경 설정 비밀값
- 실사용자 대화·운영 로그와 DB 덤프
- 설치 패키지, 모델 가중치, 임베딩 캐시
- 수집 원문 전체 ZIP, 첨부문서 원본, 중복 배포 ZIP
- 모든 PPT 중간 버전과 렌더 검사 이미지
- 로컬 도구 호스팅 상태 및 인증 설정

수집 원본·임베딩은 실행 시 별도로 준비합니다. 원본은 삭제하지 않았습니다. `excluded.json`은 제외된 배포 ZIP의 기록이며 모든 로컬 임시 파일의 전수 목록은 아닙니다.

## 원본 보존

노트북은 코드와 설명을 보존하고 출력·실행횟수·런타임 메타데이터만 제거합니다. XLSX와 PPTX는 데이터·본문·레이아웃을 편집하지 않고 해시로 동일성을 확인합니다. 과거 설명에 남은 로컬 경로·버전 이름은 당시 자료의 출처 정보일 수 있습니다.

## 공개 범위

개인 저장소는 최초 생성 시 비공개로 설정합니다. 팀 저장소의 별도 브랜치는 팀 저장소의 공개 범위를 따릅니다. 업로드된 같은 자료는 팀 저장소에서 공개될 수 있으므로 양쪽에 동일한 검사 기준을 적용합니다.

자동 패턴 검사는 보안 보증이나 법적 재배포 권한 확인을 대체하지 않습니다. 실제 운영 데이터를 추가하기 전에는 내용 검수를 별도로 진행합니다.
