# 실행과 입력자료

## 검색평가

`evaluators/dataset-4.1-no-filter/` 아래 각 방식의 Colab 노트북과 평가기 ZIP을 사용합니다. 노트북은 일반적으로 평가데이터셋 XLSX, KDIC_output.zip, 방식별 평가기 ZIP을 요구합니다. 코드 전용 ZIP은 소스에서 다시 묶어 포함했습니다.

크롤링 산출물 `KDIC_output.zip`과 임베딩은 별도 준비합니다. 같은 청크 ID 집합을 사용해야 Gold 평가가 가능합니다. 노트북별 파일 경로·시트 매핑·설치 버전을 확인하세요. API 비밀값은 환경변수 또는 Colab Secrets에서 읽고 코드에 커밋하지 않습니다. 과거 getpass 방식은 기록으로 남겨 두었습니다.

## 대시보드

HTML 파일을 내려받아 브라우저로 열고 해당 도구가 지원하는 평가 결과 ZIP/XLSX/JSON을 넣습니다. 버전별 지원 형식은 각 설명서를 따릅니다. 외부 CDN을 사용하는 파일은 인터넷 연결이 필요합니다. 브라우저 저장소의 데이터는 다른 사람과 자동 공유되지 않습니다.

## 관리자 UI

AWS 스냅샷은 Python 서비스와 관리자 HTML을 함께 보관한 것입니다. PostgreSQL, Elasticsearch/Nori, 모델·데이터, HCX 키, 관리자 인증, 런타임 경로를 별도 구성해야 합니다. 운영 UI의 실제 동작 검증에는 이 백엔드가 필요합니다. README만 보고 운영 DB에 모든 SQL을 일괄 실행하지 마세요. 기존 스키마와 마이그레이션 순서를 먼저 확인합니다.

## 독립 프로토타입

`archive/`는 개발 과정 보존본입니다. 일부 예제 데이터·로컬 호스팅 설정은 배포에서 빠져 있어 추가 입력이 필요할 수 있습니다. 버전별 requirements/package.json을 구분하고 저장소 전체에 한 번에 의존성을 설치하지 않습니다.

## 실행 비용

검색 평가의 임베딩 호출·답변 비교·LLM 리포트·캐시 답변 생성은 비용과 시간이 들 수 있습니다. 이번 자료 업로드 과정에서는 유료 모델 평가나 운영 반영을 실행하지 않았습니다.
