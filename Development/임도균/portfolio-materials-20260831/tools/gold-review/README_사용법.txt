KDIC Gold 검수 도구
====================

1. 실행하기.bat를 더블클릭합니다.
2. 브라우저에서 http://localhost:3000 을 엽니다.
3. 왼쪽에서 질문을 선택합니다.
4. Gold 청크 ID를 눌러 본문을 세로로 펼쳐 읽습니다.
5. 같은 문서의 다른 청크와 비교해 Gold를 추가하거나 제거합니다.
6. 검수 상태, 정답 요약, 메모를 입력합니다.
7. 우측 상단의 'CSV 내보내기'를 눌러 새 파일로 저장합니다.

중요
----
- 원본 CSV는 자동으로 덮어쓰지 않습니다.
- 화면에서 수정한 내용은 반드시 'CSV 내보내기'로 저장해야 합니다.
- 팀원이 다른 파일을 검토할 때는 상단의 'CSV 열기', '청크 열기'를 사용합니다.
- CSV는 UTF-8 또는 CP949(EUC-KR)를 지원합니다.
- 브라우저 탭을 닫기 전에 수정본을 내보내세요.
