# 실행 안내

1. 전체 패키지 ZIP을 PC에서 압축 해제합니다.
2. Colab에서 `KDIC_Structured_Hybrid_ParentChild_업무필터없음_평가_Colab.ipynb`를 엽니다.
3. 업로드 셀에서 평가기 ZIP, `KDIC_output.zip`, `Evaluation_DataSet_v3.5.xlsx` 3개를 선택합니다.
4. 위에서 아래로 실행하고 마지막 결과 ZIP을 다운로드합니다.

## 고정 조건

- 업무 분류/필터: 없음
- Structured Dense 입력: title, section_title, heading_path, content
- Dense/BM25-Nori 후보: 각각 Top-20
- Weighted RRF: Dense 0.85, Nori 0.15, c=10
- 최종 Child: Top-10
- Parent-Child: seed Child 5, Parent 최대 3, 인접 ±1, Parent당 최대 3, 전체 최대 10
- Reranker: 사용하지 않음
