# KDIC Structured Hybrid + Parent-Child + Reranker Colab 실행 안내

## 포함 파일

1. `KDIC_Structured_Hybrid_ParentChild_Reranker_업무필터없음_평가_Colab.ipynb`
2. `KDIC_Structured_Hybrid_ParentChild_Reranker_평가기.zip`
3. `KDIC_output.zip`
4. `test_dataset_4.1.xlsx`

평가데이터셋의 질문과 Gold 내용은 수정하지 않았습니다. `evaluation_target=Y`인 120개 질문을 평가합니다.

## 실행 방법

1. Colab에서 노트북을 엽니다.
2. `런타임 → 런타임 유형 변경 → T4 GPU`를 선택합니다.
3. 첫 번째 셀부터 순서대로 실행합니다.
4. 업로드 화면에서 위 준비 파일 중 노트북을 제외한 3개 파일을 한 번에 올립니다.
5. Colab Secrets에 `HCX_API_KEY`가 있으면 자동 사용하고, 없으면 보안 입력창에 키 값만 입력합니다.
6. 전체 평가가 끝나면 결과 ZIP이 자동으로 내려받아집니다.

## 검색·확장 순서

```text
Structured BGE-M3 Dense Top-20
                 +
BM25-Nori Discard Top-20
                 ↓
Weighted RRF (Dense 0.85 / Nori 0.15 / c=10)
                 ↓
Hybrid 후보 Child 20개
                 ↓
BAAI/bge-reranker-v2-m3 재정렬
                 ↓
검색 평가용 Child Top-10
                 ↓
상위 seed Child 5개 보존
                 ↓
선택된 Parent의 인접 청크 ±1 확장
                 ↓
답변 컨텍스트 최대 10개 청크
```

업무 분류와 업무 필터는 적용하지 않습니다.

## 결과 파일

- `question_results.csv`: 질문별 검색 결과, Reranker 전후 지표, Parent-Child 확장 지표
- `summary.json`: 전체 및 도메인별 요약
- `summary_by_domain.csv`: Reranker 이후 도메인별 검색·확장 지표
- `summary_before_rerank_by_domain.csv`: Reranker 이전 도메인별 검색 지표
- `run_config.json`: 사용 파라미터
- `structured_embedding_cache.jsonl`: Structured Dense 임베딩 캐시
- `reranker_score_cache.jsonl`: 질문-청크 Reranker 점수 캐시

## 지표 기준

- 일반 검색 지표: Reranker 이후 Child Top-10 기준
- `before_*`: Reranker 이전 Hybrid 순위 기준
- Parent-Child 지표: Reranker 상위 Child를 인접 청크로 확장한 컨텍스트 기준

Parent-Child 확장 결과는 일반 검색 순위를 대체하지 않습니다. 검색 방식 비교는 일반 검색 지표로 하고, 답변에 필요한 근거 범위가 넓어졌는지는 확장 지표로 따로 판단합니다.
