# 대표 발표자료

프로젝트 3의 `easy_질의분석흐름수정` 파일은 이 작업공간에 남은 최신 시각의 easy 발표본입니다. 스토리덱과 프로젝트 2 최종정리본도 개발 과정 기록으로 보관합니다. 모든 중간 v1~v25·렌더 이미지는 중복을 줄이기 위해 제외했습니다.

발표 파일은 내용을 고치지 않은 원본 사본입니다. 당시 화면·실험 수치·표현이 남아 있으므로 현재 운영 상태와 구분해야 합니다. 팀 전체 발표자료이며 개인 단독 결과물로 표현하지 않습니다.

`build-sources/`는 초기에 사용한 작성 코드와 소스 메모입니다. 이후 덱 편집을 모두 반영한 재현용 빌더라고 보장하지 않으며, 메모가 참조하는 이미지·로컬 경로는 별도 준비가 필요합니다.
