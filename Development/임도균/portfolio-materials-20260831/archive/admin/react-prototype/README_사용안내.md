# KDIC RAG 관리자 UI 프로토타입

종합프로젝트의 관리자 기능을 빠르게 논의하고 구현 범위를 확정하기 위한 로컬 웹 프로토타입입니다.

## 실행 방법

1. `실행하기.bat`을 더블클릭합니다.
2. 터미널에 서버 주소가 표시되면 브라우저에서 `http://localhost:3000`을 엽니다.
3. 종료할 때는 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

## 현재 연결된 실제 자료

- 페이지: `public/data/documents.jsonl` — 87건
- 청크: `public/data/chunks.jsonl` — 427건
- 업무: 예금자보호제도, 예금보험금 안내, 고객 미수령금 신청, 착오송금 반환 신청, 채무조정 안내, 은닉재산 신고
- 현재 검색 설정 표시: Structured Dense V2 0.7 + BM25 Nori-none 0.3, Weighted RRF K=10, 후보 깊이 각 20, 최종 Top-K=5
- 평가 기준 표시: Evaluation DataSet v5, 270문항

## 실제 동작과 시뮬레이션 구분

### 실제 데이터로 동작

- 페이지·청크 목록 조회
- 업무별 필터링 및 텍스트 검색
- 청크 본문 펼쳐보기
- 원문 URL 확인
- 실제 업무별 페이지·청크 수 집계

### 화면 검토용 시뮬레이션

- 신규 URL 파싱·청킹 미리보기와 승인
- 페이지 비활성화·재수집
- 파라미터 A/B 검색 결과
- 재수집·재청킹·재임베딩 트리거 및 상태
- 테스트셋 기반 변경 전후 품질 비교

시뮬레이션 버튼은 원본 JSONL을 변경하거나 실제 인덱스를 삭제하지 않습니다.

## 실제 기능으로 연결할 때의 권장 순서

1. 조회 API: 페이지·청크 목록, 상세 조회, 필터·페이지네이션
2. 작업 API: URL 파싱 미리보기, 청킹 미리보기, 적재 승인
3. 작업 큐: 재수집·재청킹·재임베딩 실행과 상태 조회
4. 비교 API: 기준 설정과 후보 설정으로 동일 질문 검색
5. 평가 실행기: 테스트셋 실행, 결과 저장, 변경 전후 비교
6. 안전장치: 삭제 대신 비활성화, 승인 단계, 작업 이력과 롤백

## 원본 보호

프로토타입은 원본 프로젝트 파일을 직접 읽거나 수정하지 않습니다. 필요한 JSONL을 `public/data`로 복사하여 사용합니다.
