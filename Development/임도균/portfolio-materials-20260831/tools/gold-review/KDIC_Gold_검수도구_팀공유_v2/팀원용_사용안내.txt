KDIC Gold 검수 도구 - 팀원용
============================

실행 방법
---------
1. KDIC_Gold_검수도구_팀공유.html 파일을 더블클릭합니다.
2. 별도 설치나 인터넷 연결 없이 브라우저에서 바로 사용할 수 있습니다.

검수 방법
---------
1. 왼쪽에서 질문을 선택합니다.
2. Gold 청크 ID를 눌러 본문을 펼쳐 읽습니다.
3. 같은 문서의 다른 청크와 비교합니다.
4. '전체 427개 청크'를 선택하면 모든 업무·문서에서 검색할 수 있습니다.
5. 필요한 경우 Gold 청크를 추가하거나 제거합니다.
6. 검수 상태, 정답 요약, 메모를 입력합니다.
7. 작업이 끝나면 우측 상단의 'CSV 내보내기'를 누릅니다.

4명이 수정사항을 주고받는 방법
-----------------------------
1. 상단 '4인 협업 모드'에 본인 이름을 입력합니다.
2. 작업 후 '수정 내용 보내기'를 누릅니다.
3. 생성된 KDIC_Gold_수정내용_이름_날짜.json을 취합 담당자에게 보냅니다.
4. 취합 담당자는 '팀원 수정본 합치기'를 누르고 여러 JSON을 한 번에 선택합니다.
5. 충돌이 없으면 자동 반영됩니다.
6. 같은 필드를 서로 다르게 고친 충돌은 기존 값을 보존하고 화면에 알려줍니다.
7. 취합 후 전체 CSV를 내보내 다음 기준본으로 공유합니다.

업무 분담 검수
-------------
- 업무 필터에서 담당 업무를 선택합니다.
- 왼쪽의 '현재 목록만 내보내기'를 누르면 담당 질문만 저장됩니다.
- 파일명에 검수자 이름을 덧붙여 취합 담당자에게 전달하는 것을 권장합니다.

주의 사항
---------
- HTML 파일 안에는 제작 당시의 평가 질문 128개와 청크 427개가 들어 있습니다.
- 화면에서 수정한 내용은 HTML 원본에 자동 저장되지 않습니다.
- 브라우저를 닫기 전에 반드시 'CSV 내보내기'로 결과를 저장하세요.
- 팀원이 새로 내보낸 CSV는 상단의 'CSV 열기'로 다시 불러올 수 있습니다.
- 청크 파일이 변경된 경우 상단의 '청크 열기'에서 새 chunks.jsonl을 선택할 수 있습니다.
- 현재 HTML 방식은 구글 문서 같은 초 단위 실시간 동기화가 아니라 수정본 파일을 합치는 방식입니다.
