# KDIC RAG · 실험 도구와 운영 관리자

예금보험공사 RAG 챗봇 프로젝트에서 **임도균이 담당한 검색 실험·평가 도구·관리자 UI**와 관련 팀 산출물을 정리한 자료 저장소입니다.

> 자료 보존 기준일: 2026-08-31. 이 저장소는 배포용 단일 애플리케이션이 아니라, 독립적으로 개발한 도구와 실험 패키지를 모은 아카이브입니다. 이번 업로드는 AWS 서비스나 팀 저장소의 기본 브랜치를 변경하지 않습니다.

## 프로젝트와 역할

- 팀: 6조 — 유민규(팀장), 임도균, 박주영
- 임도균 중심 작업: 검색 방식별 평가기, 평가데이터셋 검수 지원, 검색평가 대시보드, 관리자 UI 및 운영 연동, 실험·선정 과정 문서화
- 팀 공동 작업: 질의분석·검색·답변 생성 파이프라인의 설계·검증과 챗봇 통합
- 크롤링·청킹 기반 파이프라인과 팀원 챗봇 코드는 연동 의존성으로 포함하며, 개인 단독 구현으로 주장하지 않습니다.
- 원본 팀 저장소: [AI-NLP05-Team06/Project03](https://github.com/AI-NLP05-Team06/Project03)

## 재현성과 해석

- 평가데이터셋 XLSX는 질문·Gold·라벨을 수정하지 않고 복사했습니다. 출처와 SHA-256은 [파일 목록](docs/inventory/files.json)에 기록합니다.
- `test_dataset_4.1`과 `평가 패키지 v4.1`은 이름이 비슷하지만 서로 다른 실험 버전입니다. 디렉터리를 분리했습니다.
- 검색 지표를 비교할 때 데이터셋·청크 집합·업무필터·지표 K를 함께 확인해야 합니다.
- 서로 다른 K의 결과나 여러 지표의 단순평균만으로 검색 방식의 우열을 확정하지 않습니다.
- 초기 노트북의 키 입력 방식과 설치 버전은 당시 구현 기록입니다. 최신 Colab에서 모든 패키지를 재실행한 것은 아닙니다.
- 최신 운영 스냅샷도 DB·모델·입력자료·환경변수를 준비해야 실행됩니다. HTML만으로 운영 API가 재현되는 것은 아닙니다.

## 보안·공유 범위

노트북 실행 출력과 실행 횟수를 제거하고 소스·ZIP 내부·Office XML에서 비밀정보 패턴을 검사합니다. `.env`, PEM 인증키, DB, 실제 운영 요청 로그, 설치 라이브러리, 대용량 크롤링 원본·임베딩은 배포 대상에서 제외합니다.

평가용 질문·Gold 및 평가 실행 결과는 운영 사용자 대화 로그와 구분합니다. 발표자료는 당시 실험 결과를 포함한 역사적 자료이므로 최신 운영 성능 보장으로 해석하지 않습니다.

자세한 내용: [공유 정책 및 제외 범위](docs/publication-policy.md), [검증 기록](docs/verification.md).
