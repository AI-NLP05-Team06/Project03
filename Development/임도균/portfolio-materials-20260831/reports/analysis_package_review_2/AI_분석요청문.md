# KDIC 검색 방식 선정 분석 요청

첨부된 JSON과 CSV를 바탕으로 RAG 검색 방식 선정안을 작성해 주세요.

## 분석 원칙
1. 먼저 검색 방식별 질문 수·Gold·Top-K·업무 필터 등 비교 조건이 동일한지 확인하세요.
2. Hit@3, Recall@5, MRR@10, MAP@10, Complete@5, nDCG@5, Precision@5, F1@5를 각각 해석하세요.
3. 단순 평균 1위만 고르지 말고 도메인별 편차와 실패 질문 유형을 함께 분석하세요.
4. 질문별 결과가 있으면 공통 실패, 특정 방식만 성공한 질문, Hard Negative 혼입을 찾아주세요.
5. 검색 지연시간이 있으면 품질 향상 대비 비용을 비교하세요.
6. 최종적으로 기본 검색 방식 1개와 보완용 Hybrid 후보를 제안하고 근거를 표로 정리하세요.
7. 데이터가 부족하거나 비교 조건이 다르면 확정 결론 대신 추가 실험 항목을 제안하세요.

## 원하는 출력
- 비교 조건 검증
- 전체 지표 비교
- 도메인별 강점·약점
- 대표 성공·실패 사례
- 권장 검색 방식과 선정 근거
- 다음 실험 제안
