KDIC 검색 품질 비교 대시보드 — 팀 공유용

[실행 방법]
1. 받은 ZIP 파일의 압축을 풉니다.
2. 실행하기.bat을 더블클릭합니다.
   또는 KDIC_검색품질_비교대시보드.html을 직접 더블클릭합니다.
3. 평가 결과 ZIP·CSV·JSON·XLSX 파일을 화면에 끌어 놓습니다.
4. 검색 방식 이름이 잘못 인식되면 화면 아래쪽
   "등록된 검색 방식 관리 → 이름 변경"에서 수정합니다.
5. 필요하면 "비교표 CSV 저장"으로 평균 비교표를 내려받습니다.
6. 모든 결과를 지우려면 "전체 결과 비우기"를 누릅니다.
   화면과 브라우저 저장값이 완전히 비워집니다.

[다중 청크 문항 분리 보기]
1. "평가 보기 설정"에서 다중 청크 문항 처리 방식을 고릅니다.
2. 필수 다중 청크 문항만 제외하거나, Gold가 2개 이상인 질문을 모두 제외할 수 있습니다.
3. 필터는 요약 지표·차트·도메인 성능·질문 목록·내보내기 파일에 함께 적용됩니다.
4. "다중 청크 질문만 보기"를 선택하면 해당 문항만 따로 점검할 수 있습니다.

[평가데이터 이상 의심 점검]
1. "평가데이터 진단 보기"를 눌러 자동 점검 결과를 펼칩니다.
2. 중복 평가ID, Gold 누락, 문서ID와 청크ID 불일치, Complete@5 계산 불가,
   답변 불가·추가질문 문항의 검색평가 혼입 등을 검토 후보로 보여줍니다.
3. 질문별 검색 결과의 "진단 보기"를 누르면 해당 질문의 점검 근거만 확인할 수 있습니다.
4. 자세한 진단이 필요하면 검색 결과 파일과 평가데이터셋 XLSX를 동시에 선택합니다.
5. 자동 진단은 오류 확정이 아니라 사람이 먼저 검수할 후보를 찾는 기능입니다.

[AI 분석용 자료 추출]
1. 비교할 검색 방식 결과를 모두 등록합니다.
2. "AI 분석용 ZIP 저장"을 누릅니다.
3. 생성된 KDIC_검색평가_AI분석패키지.zip을 ChatGPT, Codex 또는 다른 AI에 첨부합니다.
4. ZIP 안의 AI_분석요청문.md 기준으로 검색 방식 선정을 요청합니다.

AI 분석용 ZIP에는 다음 자료가 포함됩니다.
- 전체 평균과 도메인별 결과
- 질문별 Gold·Top-10 검색 결과
- 적용 중인 다중 청크 필터
- 평가데이터 자동 진단 후보와 판단 근거
- 8개 지표 정의와 원본 소수값
- 검색 방식별 비교 CSV
- 객관적인 비교를 위한 분석 요청문

[지원 결과]
- BGE-M3 Dense
- BGE-M3 Sparse
- BM25
- BM25-Nori
- Hybrid Search
- 같은 지표 구조를 가진 추가 검색 방식

[표시 지표]
- Hit@K (K=3)
- Recall@K (K=5)
- MRR@K (K=10)
- MAP@K (K=10)
- Complete@K (K=5)
- nDCG@K (K=5)
- Precision@K (K=5)
- F1@K (K=5)

[주의]
- Excel과 ZIP 분석 기능을 불러오기 위해 인터넷 연결이 필요합니다.
- 업로드한 평가 파일은 외부 서버로 전송되지 않고 각 팀원의 브라우저에서 처리됩니다.
- 등록한 검색 방식과 이름 변경 내용은 해당 팀원의 브라우저에만 저장됩니다.
- 다른 팀원에게 동일한 비교 결과를 전달하려면 원본 평가 결과 ZIP도 함께 공유해야 합니다.
- 이 버전은 Google Docs처럼 여러 사람이 같은 데이터를 실시간으로 공동 편집하는 구조는 아닙니다.
